## ⚡ About

I'm a B.Tech EEE student at **VIT Vellore** (2024-2028). I enjoy the part of engineering where a circuit, a microcontroller and some code all have to agree with each other.

My projects so far: an optical link that sends data from an LED to a phone camera, a wireless mine-safety monitor, and a programmable gain amplifier controlled over serial.

Looking at: semiconductor, core electrical and embedded roles.

## 🚀 Projects

|---|---|
| 📡 [**rolling-shutter-occ**](https://github.com/Sankalp-u/rolling-shutter-occ) | **Project Nyquist.** An ESP32 blinks an LED with Manchester-coded data. A rolling-shutter camera films it, and a Python decoder recovers the message from the light and dark stripes. Includes a live Flask dashboard. |
